# Практическая работа №2: Разработка миссии предприятия

## Задание (Assignment)

**Цель работы:** развитие практических навыков формулирования миссии и целей предприятия, а также постановки целей по методу SMART.

**Задачи:**
1. Провести анализ предложенных формулировок миссий (Инвестиционная компания, Минизавод по переработке молока, Компания по предоставлению банковских услуг и др.), определить их недостатки и предложить новые варианты.
2. На основе конкретного примера (компания по разработке ПО «Вектор Софт») сформулировать миссию, слоган и разработать цели по методу SMART.

## Мой вклад (My Contribution)

- Проанализированы 5 формулировок миссий (включая дополнительные примеры: фирма по производству офисной мебели и ювелирно-хозяйственная фирма).
- Выявлены типичные ошибки: подмена миссии описанием деятельности, рекламный текст, отсутствие ценностей и уникальности.
- Для каждой компании предложена новая, скорректированная формулировка миссии.
- Разработана миссия и слоган для компании «Вектор Софт» (разработка ПО).
- Сформулированы 5 целей по методу SMART с подробной проверкой по всем критериям (S, M, A, R, T).
